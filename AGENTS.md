# EcoMode — instruções para agentes

- Leia apenas os arquivos diretamente relacionados à tarefa; use buscas por nome ou texto antes de abrir arquivos grandes.
- Limite saídas de comandos e evite repetir conteúdo já apresentado.
- Para logs extensos, use `comando | ecomode` quando a saída puder ser filtrada com segurança.
- Não filtre saídas quando a ordem ou cada linha for necessária para diagnosticar o problema.
- Preserve e reporte erros, avisos, falhas e a causa relevante.
- Execute somente os testes necessários para a alteração atual.
